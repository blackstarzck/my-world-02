# My World — Digital Gallery

어두운 3D 전시 공간에서 프로젝트를 선택하고, 왼쪽의 실제 웹사이트를 조작하며 오른쪽 설명을 읽는 포트폴리오입니다. 현재 네 작품은 동작 확인용으로 만든 예시이며 실제 이력이나 작업 성과를 뜻하지 않습니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 `npm install`, `npm run dev`를 실행합니다. 로컬 주소는 `http://127.0.0.1:5173`입니다. 배포용 파일은 `npm run build`로 `dist`에 생성합니다.

## 실제 프로젝트로 교체

`src/projects.js`에서 표시 이름과 소개, 작품별 이름·주소·설명을 바꿉니다. 웹사이트 주소는 `url`, 복도에 걸 스크린샷은 `previewImage`에 넣습니다. 예를 들어 `public/images/my-project.webp`로 저장한 이미지의 주소는 `/images/my-project.webp`입니다. 화면 비율은 8:5를 권장합니다. `previewImage`를 생략하면 현재의 HTML 예시 화면을 사용합니다.

외부 웹사이트가 삽입을 허용해야 왼쪽에서 열립니다. 해당 사이트가 `X-Frame-Options` 또는 `Content-Security-Policy: frame-ancestors`로 삽입을 차단하면 그 사이트의 관리자가 허용 출처를 설정해야 합니다. 임의로 보안을 우회하지 않으며, 언제든 새 탭으로 열 수 있는 링크가 있습니다.

## 관람

- 입구에서 Enter gallery를 누릅니다.
- 복도에서는 스크롤·드래그로 이동합니다. 아래 점 또는 방향키로 작품을 정면에서 봅니다.
- 작품이나 프로젝트 열기를 누르면 실제 사이트와 설명을 엽니다. 닫기 버튼으로 선택했던 작품에 돌아옵니다.
- Index에서 전체 작품을 선택할 수 있습니다. 작은 화면의 상세는 웹사이트와 설명을 위아래로 보여줍니다.
- 배경음은 기본적으로 꺼져 있고, Sound 버튼을 누른 뒤에만 재생됩니다.

## 렌더링과 제한

브라우저가 실험 중인 HTML-in-Canvas 기능을 제공하면 Three.js HTMLTexture로 HTML 작품 화면을 캔버스 안에 그립니다. 미지원 브라우저에서는 같은 HTML을 CSS 3D로 배치하고, 3D 공간은 WebGL로 그립니다. 상세 화면은 두 방식 모두 실제 iframe이므로 클릭·입력·스크롤이 가능합니다. 브라우저 설정은 자동 변경하지 않습니다.

로컬 브라우저 검증은 호환 렌더링 경로에서 완료했습니다. 실험 기능 경로는 이를 지원하는 브라우저에서 별도 확인이 필요합니다. WebGL을 사용할 수 없으면 입장 시 프로젝트 목록을 제공합니다. 다른 주소의 iframe 내용을 캔버스 텍스처로 직접 읽지는 않습니다.

메모 예시는 브라우저 내부에만 저장되고, 삭제하지 않은 데이터는 새로고침 후에도 유지됩니다. 타이머는 해당 프로젝트를 열어 둔 동안 동작합니다. 외부 계정·메일·결제 서비스는 연결하지 않았습니다.

## 확인

`npm run check`는 작성한 JavaScript 문법을 확인하고, `npm run build`는 배포용 파일을 만듭니다. 실제 브라우저에서 입장, 작품 이동, 상세 진입·닫기, 입력·서체 변경, 색상 변경·일시 정지, 메모 저장 후 새로고침, 타이머 시작·일시 정지, 목록, 소개, 모바일 배치를 확인했습니다.

관람 흐름 참고: [Ambient Weaving Ⅱ](https://ambientweaving2.lab.zozo.jp/en). 원본 사이트의 이미지·글꼴 파일·코드를 복제하지 않았습니다. 예시 작품은 이 프로젝트에서 새로 제작했습니다.
